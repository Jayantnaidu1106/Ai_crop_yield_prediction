# Crop Yield Prediction API

A FastAPI-based REST API for predicting crop yield based on agricultural parameters using machine learning.

## Overview

This API uses a trained Random Forest model to predict crop yield (tonnes per hectare) based on various agricultural factors including crop type, season, location, area, production, rainfall, fertilizer usage, pesticide usage, and temperature.

## Features

- 🌾 **Crop Yield Prediction**: Predict yield for 40 different crop types
- 🔄 **Batch Processing**: Process multiple predictions in a single request
- 📊 **Model Information**: Get detailed information about the trained model
- 🏥 **Health Monitoring**: Built-in health check endpoints
- 📖 **Interactive Documentation**: Automatic API documentation with Swagger UI
- ✅ **Input Validation**: Comprehensive input validation using Pydantic

## Supported Crops

The API supports predictions for the following crops:
- Arhar/Tur, Bajra, Castor Seed, Coriander, Cotton(Lint)
- Cowpea(Lobia), Dry Chillies, Garlic, Ginger, Gram
- Groundnut, Horse-gram, Jowar, Jute, Linseed
- Maize, Masoor, Mesta, Moong(Green Gram), Niger Seed
- Onion, Other Rabi Pulses, Other Kharif Pulses, Peas & Beans (Pulses)
- Potato, Ragi, Rapeseed & Mustard, Rice, Safflower
- Sannhamp, Sesamum, Small Millets, Soyabean, Sugarcane
- Sunflower, Sweet Potato, Tobacco, Turmeric, Urad, Wheat

## Supported Seasons
- Autumn, Kharif, Rabi, Summer, Whole Year, Winter

## Supported States
- Currently supports: Odisha (More states can be added based on training data)

## Running the API

### Method 1: Using uvicorn directly
```bash
python -m uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```

### Method 2: Using the startup script
```bash
# Windows
start_server.bat

# Linux/Mac
./start_server.sh
```

The API will be available at:
- **Main API**: http://localhost:8000
- **Interactive Docs**: http://localhost:8000/docs
- **Alternative Docs**: http://localhost:8000/redoc

## API Endpoints

### 1. Root Endpoint
- **URL**: `GET /`
- **Description**: Basic API information and status

### 2. Health Check
- **URL**: `GET /health`
- **Description**: Check API health and model status

### 3. Single Prediction
- **URL**: `POST /predict`
- **Description**: Predict yield for a single set of parameters

**Request Body Example**:
```json
{
  "crop": "rice",
  "crop_year": 2020,
  "season": "autumn",
  "state": "odisha",
  "area": 30000.0,
  "production": 25000.0,
  "annual_rainfall": 1200.0,
  "fertilizer": 3000000.0,
  "pesticide": 12000.0,
  "temperature": 24.5
}
```

**Response Example**:
```json
{
  "predicted_yield": 0.833333,
  "input_yield_ratio": 0.833333,
  "model_confidence": "High",
  "message": "Prediction completed successfully"
}
```

### 4. Batch Prediction
- **URL**: `POST /batch-predict`
- **Description**: Process multiple predictions (max 100 per request)

### 5. Model Information
- **URL**: `GET /model-info`
- **Description**: Get information about the loaded model

## Input Parameters

| Parameter | Type | Description | Range/Options |
|-----------|------|-------------|---------------|
| crop | string | Crop type | See supported crops list |
| crop_year | integer | Year of cultivation | 1990-2030 |
| season | string | Growing season | autumn, kharif, rabi, summer, whole year, winter |
| state | string | State name | odisha (more can be added) |
| area | float | Area in hectares | > 0 |
| production | float | Production in tonnes | > 0 |
| annual_rainfall | float | Annual rainfall in mm | ≥ 0 |
| fertilizer | float | Fertilizer usage | ≥ 0 |
| pesticide | float | Pesticide usage | ≥ 0 |
| temperature | float | Average temperature in Celsius | Any |

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| predicted_yield | float | Predicted yield in tonnes per hectare |
| input_yield_ratio | float | Input production/area ratio for comparison |
| model_confidence | string | Model confidence: "High", "Medium", or "Low" |
| message | string | Success message |

## Error Handling

The API returns appropriate HTTP status codes:
- `200`: Success
- `400`: Bad Request (invalid input)
- `422`: Validation Error
- `500`: Internal Server Error
- `503`: Service Unavailable (model not loaded)

## Model Performance

The trained Random Forest model achieves:
- **R² Score**: ~0.66 on test set
- **Cross-validation R²**: ~0.91 ± 0.08
- **RMSE**: ~6.40
- **MAE**: ~1.39

## Troubleshooting

### Model not loaded error
- Ensure `crop_yield_model.pkl` and `scaler.pkl` exist
- Run the Jupyter notebook to generate model files

### Connection refused
- Check if the server is running on the correct port
- Verify no firewall is blocking the connection

### Validation errors
- Check input parameter names and types
- Ensure all required fields are provided
- Verify crop/season/state names are in the supported list

### Performance issues
- Consider using background tasks for large batch predictions
- Monitor memory usage with large models
- Use appropriate hardware for model inference
